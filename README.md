# Мои напоминания

Учебное настольное приложение для Windows на Python 3.12 и Tkinter. Напоминания и их статусы сохраняются в локальной базе SQLite.

## Что можно сделать

- Создать одноразовое или ежедневное напоминание с датой и временем.
- Получить всплывающее уведомление по расписанию. Для показа оставьте приложение запущенным.
- Выставить время на полчаса вперёд кнопкой **«Через 30 минут»** и сохранить задачу.
- Найти задачу по тексту и отфильтровать список по статусу. В главном окне статусы выделены цветом.

Главное окно использует стандартные элементы Tkinter (`ttk`). Разделы «Настройки» и «План на неделю» открывают макеты.

## Запуск на Windows

Установите Python 3.12 и скачайте репозиторий целиком, включая папку `assets`. Если у вас установлен Git, можно скачать проект следующими командами в PowerShell.

```powershell
git clone https://github.com/mikhailLav777/vpa05-reminder.git
Set-Location .\vpa05-reminder
```

В папке проекта создайте виртуальное окружение, установите зависимости из `requirements.txt` и запустите приложение.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

При первом запуске приложение создаёт файл `reminders.db` в папке проекта. Личная база и окружение `.venv` исключены из Git.

## Как проверить домашнее задание

1. Введи «Позвонить поставщику» и нажми **«Добавить задачу»**. В открывшейся форме выбери **«Сейчас»**, оставь флажок повтора выключенным и нажми **«Добавить задачу»** для сохранения. Появится уведомление.
2. Создай «Проверить остатки», выбери **«Сейчас»** и включи **«Повторять каждый день»**. После уведомления в списке появятся пометка «Ежедневно» и завтрашняя дата с тем же временем.
3. В форме ещё одной задачи нажми **«Через 30 минут»**. Проверь, что выбранное время на полчаса позже текущего, и сохрани задачу.

## Основные файлы

| Файл | Назначение |
| --- | --- |
| `main.py` | Точка запуска приложения |
| `standard_app.py` | Главное окно со списком задач |
| `live_app.py` | Форма добавления и редактирования задачи |
| `schedule_picker.py` | Выбор даты, времени и быстрого интервала |
| `database.py` | Сохранение задач и расчёт ежедневного повтора |
| `notifications.py` | Проверка расписания и показ уведомлений |
