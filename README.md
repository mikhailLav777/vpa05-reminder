# Мои напоминания — учебный прототип

Приложение для Windows на Python 3.12 и Tkinter. Текущая версия демонстрирует главный экран, фильтрацию задач, поиск, отметку выполнения и переходы к макетам дополнительных экранов.

## Что работает

- Главное окно с фиолетовым фоном, скруглёнными элементами и текущими датой и временем компьютера.
- Пять демонстрационных задач и прокрутка списка.
- Разделы «Все задачи», «Ожидает», «Просрочено», «Готово», «Отменено».
- Поиск по названию и описанию без учёта регистра букв. Поиск и выбранный статус применяются одновременно; список обновляется при вводе.
- Сообщение «Задачи не найдены» и счётчик показанных задач.
- Галочка выполнения: задача получает статус «Готово». Повторное нажатие возвращает предыдущий статус. Для изначально выполненного примера снятие галочки устанавливает «Ожидает».
- Отменённые задачи сохраняют свой статус при нажатии галочки.
- Вертикальный перелив пустого поля новой задачи. Подсветка скрывается при работе с вводом, поиском и демонстрационной кнопкой микрофона.
- Открытие изображений подробностей, настроек, недельного плана и уведомления.
- Настоящие кнопки «Назад на главную», «По ширине», «Вписать целиком», а также прокрутка макета и закрытие просмотра.
- Фильтр, поиск, введённый заголовок и отметки выполнения сохраняются при возврате из просмотра макета.

## Что пока демонстрационное

В интерфейсе используются пять примеров из кода. Изменения их статусов хранятся в оперативной памяти до закрытия приложения. При следующем запуске восстанавливаются исходные примеры.

Дополнительные экраны — статические изображения. Нарисованные внутри них поля, переключатели и кнопки не выполняют действий. В просмотре подробностей над изображением отдельно показаны название, описание и текущий статус выбранной демонстрационной задачи. Данные внутри изображения являются примером оформления.

Кнопки добавления задачи, шаблонов, «Все даты» и диктовки пока выводят пояснение. Захват звука и распознавание речи не запускаются.

Уведомление открывается вручную кнопкой «Пример уведомления». Проверка расписания, звуковые сигналы, перенос уведомления и работа в фоне ещё не подключены.

## Установка на Windows

1. Установите Python 3.12.
2. Скопируйте проект целиком, включая папку `assets`.
3. Откройте PowerShell в папке проекта.
4. При первом запуске создайте окружение:

```powershell
py -3.12 -m venv .venv
```

5. Установите зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

6. Запустите приложение:

```powershell
.\.venv\Scripts\python.exe main.py
```

Если окружение уже создано и зависимости установлены, достаточно последней команды. Активация окружения для этих команд не требуется.

## Файлы проекта

| Файл или папка | Назначение |
|---|---|
| `main.py` | Запуск приложения |
| `gui.py` | Оформление, демонстрационные задачи, фильтры, поиск и подсветка |
| `demo_completion.py` | Галочки выполнения и возврат статуса демонстрационных задач |
| `mockup_navigation.py` | Переходы к изображениям дополнительных экранов |
| `database.py` | Отдельный модуль работы с SQLite; к интерфейсу прототипа не подключён |
| `assets/` | Изображения `details.png`, `settings.png`, `week.png`, `notification.png` |
| `requirements.txt` | Внешняя зависимость `Pillow==13.0.0` |
| `prompt.txt` | Требования и согласованный объём проекта |
| `.gitignore` | Исключения для истории Git |

Tkinter и SQLite доступны в используемой установке Python. Дополнительно устанавливается Pillow для сглаживания элементов и просмотра изображений.

## Проверка перед демонстрацией

1. При пустом поиске в разделе «Все задачи» видны пять карточек, в разделе «Ожидает» — две.
2. В разделе «Ожидает» запрос `поставщик` оставляет задачу «Связаться с поставщиком».
3. В разделе «Готово» тот же запрос показывает «Задачи не найдены». Удаление поискового текста восстанавливает список выбранного раздела.
4. После выполнения ожидающей задачи она появляется в разделе «Готово». Снятие галочки возвращает её обратно; общее число задач остаётся равным пяти.
5. Все четыре макета открываются, масштабируются и закрываются. Возврат сохраняет состояние главного экрана.
6. После закрытия и повторного запуска приложения демонстрационные статусы сбрасываются.

## Локальные данные

Личная база `reminders.db`, её служебные файлы, окружение `.venv`, кэш Python и скачанный `assets.zip` исключены через `.gitignore`. В Git сохраняются исходный код, документация и распакованные изображения макетов.

Модуль `database.py` сохранён для дальнейшего развития. Главное окно прототипа не читает и не изменяет личную базу.
